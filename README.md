## 🌟 Overview

Welcome to the source repository for my personal developer portfolio. This website is crafted to present my engineering work, technical skill sets, professional career trajectory, and leadership experiences to recruiters, collaborators, and fellow developers.

### ✨ Key Highlights

- **⚡ Fast & Lightweight**: Engineered with native Angular Signals and standalone components, compiling to an initial transfer payload under **100 kB** without third-party component libraries.
- **🌌 Ambient Constellation Canvas**: GPU-accelerated HTML5 canvas background responding smoothly to cursor movement and scroll position.
- **💼 Dual-Track Career Timeline**: Clear demarcation between professional software engineering roles and university leadership/mentorship milestones.
- **📂 Interactive Projects Showcase**: Filterable gallery across Full-Stack, Frontend, and AI/ML categories with in-depth architecture modal views.
- **🎯 Categorized Tech Stack**: Structured skill matrix with official brand vector icons and proficiency levels.
- **📬 Responsive Contact Channel**: Integrated Angular Reactive Form with client-side validation and quick email clipboard actions.
- **📱 Mobile-First & Accessible**: Fluid typography, responsive grid layouts, and keyboard-accessible navigation.

## 🚀 Getting Started

Follow these instructions to run the portfolio locally on your machine.

### Prerequisites

Ensure you have the following installed:
* **Node.js**: `v18.19+`, `v20+`, or `v22+`
* **npm**: `v10+`

### Installation & Local Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/chinmaya-704/portfolio.git
   cd portfolio
   ```

2. **Install project dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```

4. **View in browser**:  
   Open [http://localhost:4200](http://localhost:4200) in your browser. The application will hot-reload automatically as you edit files.

### Production Build

To compile and bundle the application for production:

```bash
npm run build
```

The optimized static build will be generated in `dist/portfolio/browser/`.

## 🌐 Deployment to Vercel

This repository is pre-configured for one-click continuous deployment with **Vercel**:

1. Import the repository into your [Vercel Dashboard](https://vercel.com/new).
2. Set the **Output Directory** to:
   ```
   dist/portfolio/browser
   ```
3. Deploy! The included [`vercel.json`](vercel.json) handles Single Page Application (SPA) routing to prevent 404s on page refresh or direct section links.
